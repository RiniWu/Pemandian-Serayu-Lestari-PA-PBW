# 🏊 Pemandian Serayu Lestari — Website Company Profile

Website resmi **Pemandian Serayu Lestari** sebagai media informasi dan promosi digital berbasis web. Dibangun sebagai proyek akhir mata kuliah Pemrograman Berbasis Web, Program Studi Sistem Informasi, Fakultas Teknik, Universitas Mulawarman.

---

## 📋 Deskripsi Aplikasi

Website Pemandian Serayu Lestari dirancang sebagai platform *company profile* berbasis web yang berfungsi sebagai pusat informasi resmi bagi masyarakat. Sistem ini menjawab permasalahan keterbatasan akses informasi yang selama ini masih mengandalkan metode konvensional seperti baliho dan promosi dari mulut ke mulut.

Website menyajikan informasi secara lengkap, akurat, dan mudah diakses kapan saja, mulai dari harga tiket, jam operasional, daftar fasilitas, galeri visual, hingga lokasi terintegrasi peta digital. Selain itu, tersedia fitur ulasan dan feedback sebagai sarana interaksi antara pengunjung dan pengelola.

Sistem ini melayani dua jenis pengguna:
- **User (Pengunjung)** — mengakses informasi wisata secara publik
- **Admin (Pengelola)** — mengelola seluruh konten melalui panel dashboard khusus

---

## ✨ Fitur Website

### 👤 Halaman Pengunjung (User)
| Menu | Fungsi |
|---|---|
| **Beranda (Homepage)** | Menampilkan gambaran umum wisata, hero section, highlight fasilitas, serta statistik ringkas (pengunjung, rating, jumlah fasilitas) |
| **Carousel Foto** | Menampilkan foto-foto lokasi wisata secara bergantian dan interaktif |
| **Informasi & Profil** | Profil singkat wisata, lokasi, jam operasional, harga tiket, dan daftar fasilitas secara dinamis |
| **Fasilitas** | Daftar lengkap fasilitas dalam tampilan grid berbasis kartu, dilengkapi gambar dan deskripsi |
| **Galeri** | Koleksi foto asli lokasi wisata yang dapat dilihat secara interaktif (*lightbox*) |
| **Lokasi** | Integrasi peta digital (Google Maps) dengan informasi alamat, jam buka, dan kontak, serta tombol *"Buka di Google Maps"* |
| **Ulasan (Feedback)** | Menampilkan ulasan yang telah disetujui admin; pengunjung dapat mengirim ulasan beserta rating |

### 🔐 Halaman Admin (Dashboard)
| Menu | Fungsi |
|---|---|
| **Login** | Autentikasi admin dengan username & password sebelum mengakses panel pengelola |
| **Dashboard Utama** | Ringkasan statistik real-time: Total Wisata, Wisata Aktif, Total Ulasan, Ulasan Menunggu |
| **Manajemen Fasilitas** | Operasi CRUD (tambah, edit, hapus) data fasilitas beserta foto dan deskripsi |
| **Manajemen Galeri** | Unggah, edit keterangan, dan hapus foto galeri |
| **Moderasi Ulasan** | Tinjau, setujui (*approve*), atau hapus (*reject*) ulasan yang masuk dari pengunjung |

---

## 🛠️ Teknologi yang Digunakan

- **Backend:** PHP (Native MVC)
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
- **Arsitektur:** Model-View-Controller (MVC)
- **Server:** Apache (dengan konfigurasi `.htaccess` untuk *clean URL*)
- **Library:** Lightbox.js (galeri interaktif), Google Maps Embed API
